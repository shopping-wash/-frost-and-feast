# 雪原の商店：高品質3Dキャラクター制作・受入仕様

## 品質ゲート
- 既存の箱・球・円柱を組み合わせた兵士は最終アセットとして採用しない。
- 参考コンセプト：フード付き革鎧の弓兵、巨大な紋章盾を持つ重装盾兵、毛皮・金属鎧・大剣を備える傭兵。
- 各兵種を別メッシュ・別シルエットで制作し、スマートフォン画面の戦闘カメラ距離でも識別できること。
- Lv1〜Lv3で体格・身長を変えない。装備差分と攻撃・防御・HPのみを変える。
- レベル別差分は武器・盾・兜・肩当て・マント・装飾の別ノードで切替可能にする。

## アセット構成
assets/characters/archer.glb
assets/characters/shieldbearer.glb
assets/characters/mercenary.glb

各GLBには、骨格、テクスチャ、Idle / Walk / Run / Attack / Hit / Deathのアニメーションを含める。弓兵はDraw / Release、盾兵はBlockを追加する。装備ノード名は level_1, level_2, level_3 とする。

## ゲーム統合の受入条件
1. GLBをThree.js GLTFLoaderで読み込み、ロード失敗時に明示的なエラーを表示する。
2. 同じ兵種はレベルにかかわらず同じスケールを使用する。
3. 戦闘モーションが実際の武器・盾の動きに一致する。
4. スマホで表示と動作を検証する。
5. 既存のメインゲームを変更する前に独立試作版で確認する。

## 現状
高品質GLBファイルは未入手・未制作。現状のbattle-squad-prototype.htmlは簡易形状による仮表示であり、本仕様を満たさない。Quaternius等のローポリ素材はリギング検証候補であって、目標ビジュアルの代替ではない。
